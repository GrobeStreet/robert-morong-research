What it measures

Accuracy, honestly

Wilson and bootstrap intervals on every score, macro-F1, and an estimate of how many cases you would need to detect a given gap.

Robustness

Paraphrase, case, whitespace and option-order perturbations, reported as the drop against your baseline.

Consistency and calibration

Run-to-run agreement across repeated samples, plus Brier score and expected calibration error.

What this kit will not do

  • It measures the things listed above. It does not test safety, bias, security or domain correctness beyond the cases you supply.
  • The quality of the verdict depends on the quality and size of your test set. The scorecard tells you how many cases you would need to detect a given gap.

Questions

Do I need an API key to try it?

No. The kit ships with an offline mock model, so you can run python run_eval.py and see a complete scorecard immediately. The mock is for learning the workflow; it says nothing about your real model.

Which models does it work with?

OpenAI, Anthropic, and any OpenAI-compatible endpoint, including local servers such as Ollama, vLLM and LM Studio, so your test data can stay on your machine.

Do I need to be a developer?

Basic Python is enough: run one command, edit a CSV and a JSON config. The Starter edition is a guide plus templates and can be read without running anything.

Can I use it commercially?

Yes, for your own projects and products. You may not resell the kit itself. Pro includes a team license for up to 10 seats.

What does the verdict mean, and can I trust it?

The verdict is a transparent rule over the measured numbers (for example, the lower bound of the accuracy interval against a threshold you set). It is a decision aid, not a guarantee. A Ship verdict means your test set did not find a problem, not that none exists.
